# Gold summary rules 1.0.0

One row represents one original level-0 chunk, in artifact order, including its overlap context. No parent summaries, clustering, category extraction or complete metric inventory are required.

## Information units and evidence

Inventory distinct important propositions: scope/purpose, central definitions, principal requirements or findings, decision thresholds, actions, limitations and exceptions. This is a summary inventory, not a requirement to reproduce every source statement. Similar statements with different objects, conditions or values remain distinct. Tables require the applicable headers, units, scope paragraph and footnotes as evidence when these determine meaning.

Each unit has `id`, `claim`, positive integer `weight` (1 background, 2 important, 3 central), boolean `critical`, boolean `included`, `omission_reason` and nonempty `evidence`. Mark critical when losing the proposition would materially misstate applicability, a central requirement, a decision boundary, an exception or a principal conclusion. Record omitted units and explain the budget or relevance decision. A critical unit cannot be omitted in published gold. If all critical units cannot fit, report the conflict and obtain a larger budget or narrower evaluation scope; do not silently weaken units or exceed the budget.

Each evidence span has `line`, zero-based `start`, exclusive `end`, and exact `quote`, indexing Unicode code points in the canonical content field. A unit may require several spans together, e.g. requirement + exception. Evidence must lie in this chunk's regular or overlap input. External context may inform a limitation but never silently supply missing evidence. All factual summary claims must map to included units; their evidence supports the complete claim, not just matching words. Reviewers enforce this semantic condition.

## Drafting

Synthesize clear prose or concise bullets in the source language. Preserve modality (shall/should/may), actor, object, comparator, number, unit, time, condition, negation and exception wherever retained. Do not turn alternatives into cumulative requirements, collapse different thresholds, or infer a numerical value or missing OCR text. Prefer informative source statements over generic descriptions such as “this chunk discusses requirements”. Remove repetition without dropping distinctions.

Limit `summary_text` to the run's `budget_chars`, counted as non-whitespace Unicode code points, including punctuation. The budget applies to each source-language summary; `summary_text_en` is an accurate translation, not another independently budgeted summary. English chunks use an empty English translation field. Non-English readable chunks require an English translation and translated keywords. Use source-language keywords that describe the actual summary. Use normalized `en`, `zh-cn` or other source-language tags; preserve mixed-language content sensibly and disclose any metadata/content mismatch instead of relabeling untranslated prose.

Content-free/image-only chunks use `empty_reason`, empty summaries, keywords and units. A readable heading or caption is content, so summarize it briefly rather than claiming the chunk is empty. Material inaccessible image information or parser damage requires an explicit limitation and blocks a claim that affected gold is complete.

## Audits

Completeness: reread the full input in source order; account for all chunks and information units; check regular payload versus overlap, late-position facts, tables and omissions. Explain noncritical omissions and verify no critical unit is lost.

Correctness: map every summary claim to included units; check complete evidence and all semantic qualifiers, numeric fidelity and translation. Do not use exact quotation coverage as a score for paraphrased gold. Record reviewer identity and concrete findings in each row's `completeness_review` and `correctness_review` objects (`reviewer`, `notes`). The run records `review_mode` (`independent` or `self`), `limitations` and `blocking_issues`. Publish only after both reviews and with no blocking issues; independent review must involve an agent distinct from the author, though both may use the same model. Agent review is not human certification.
